# Prouni Data Insights

Análise exploratória e dashboard sobre as bolsas concedidas pelo Programa Universidade para Todos (Prouni) entre 2005 e 2019. O projeto transforma os registros disponibilizados no Kaggle em um fluxo de preparação com Python e em um relatório interativo de três páginas no Power BI.

## Visão geral

O projeto foi construído para facilitar a leitura da evolução e da distribuição das bolsas do Prouni. A análise permite observar:

- a evolução anual das concessões;
- a participação de bolsas integrais e parciais de 50%;
- a distribuição por região e unidade federativa;
- os recortes por sexo, raça e idade;
- a participação das modalidades presencial e EaD.

No período analisado, o dashboard consolida aproximadamente **2,68 milhões de bolsas**: **1,87 milhão de bolsas integrais** e **810,89 mil bolsas parciais de 50%**.

## Principais resultados

- O Sudeste concentra o maior volume no período, com cerca de 1,285 milhão de bolsas.
- As bolsas integrais representam aproximadamente 70% do total consolidado.
- O ensino presencial responde por 81,35% das bolsas; a modalidade EaD representa 18,65%.
- O painel permite acompanhar diferenças temporais por sexo, raça, região e tipo de bolsa, sem reduzir esses recortes a uma única leitura agregada.

Os valores acima foram conferidos nas capturas atuais do dashboard e podem mudar caso as fontes ou os filtros do relatório sejam atualizados.

## Fonte e preparação dos dados

O notebook [`notebooks/preprocessed.ipynb`](notebooks/preprocessed.ipynb) baixa, por meio do KaggleHub, o dataset [Brasil Students Scholarship — Prouni 2005–2019](https://www.kaggle.com/datasets/lfarhat/brasil-students-scholarship-prouni-20052019).

O processo de preparação:

1. padroniza os nomes das colunas;
2. remove registros com valores ausentes;
3. exclui CPF, data de nascimento e código e-MEC;
4. mantém idades entre 15 e 90 anos;
5. remove a categoria de bolsa complementar de 25%;
6. exporta o resultado para `data/processed/prouni_2005_2019_processed.csv`.

O CSV tratado é gerado localmente e não é versionado no repositório.

## Análise exploratória

O notebook [`notebooks/prouni_insights.ipynb`](notebooks/prouni_insights.ipynb) usa pandas, Plotly e ipywidgets para criar gráficos interativos de:

- quantidade de bolsas por tipo e faixa etária;
- distribuição por sexo e raça;
- variação e crescimento por períodos anuais, trienais ou quinquenais;
- comparação entre regiões;
- mapa de bolsas por UF com o GeoJSON local.

Os gráficos Plotly podem ser exportados em PNG com Kaleido para subpastas de `figures/`.

## Como executar

### 1. Clonar o repositório

```powershell
git clone https://github.com/cidade-felipe/Prouni-Data-Insights.git
cd Prouni-Data-Insights
```

### 2. Criar e ativar o ambiente virtual

```powershell
python -m venv venv
.\venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

O notebook exploratório também importa `ipyfilechooser`, ainda não declarado no `requirements.txt`. Para executar o estado atual do notebook, instale-o no mesmo ambiente:

```powershell
python -m pip install ipyfilechooser
```

### 3. Preparar os dados

Abra `notebooks/preprocessed.ipynb` com o diretório de trabalho em `notebooks/` e execute as células em ordem. O download pelo KaggleHub exige internet e pode solicitar autenticação.

Ao final, o arquivo será criado em:

```text
data/processed/prouni_2005_2019_processed.csv
```

### 4. Executar a análise exploratória

O notebook `prouni_insights.ipynb` atualmente procura o CSV em `data/prouni_2005_2019_processed.csv`. Até que os caminhos dos notebooks sejam alinhados, copie o arquivo gerado antes de executar a análise:

```powershell
Copy-Item `
  .\data\processed\prouni_2005_2019_processed.csv `
  .\data\prouni_2005_2019_processed.csv
```

Depois, abra `notebooks/prouni_insights.ipynb` com o diretório de trabalho em `notebooks/` e execute as células em ordem.

### 5. Abrir o relatório

Para explorar ou editar o dashboard, abra `reports/prouni-data-report.pbix` no Power BI Desktop. Caso queira apenas consultar o resultado, use o PDF ou as imagens incluídas no repositório.

## Limitações atuais

- Os dois notebooks ainda usam caminhos diferentes para o CSV processado.
- `ipyfilechooser` ainda não consta no arquivo de dependências.
- Não há testes automatizados nem pipeline de atualização dos dados.
- A edição e a atualização do `.pbix` dependem do Power BI Desktop.
